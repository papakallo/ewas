\subsection{2.2. Reference Documents and Technical Evidence}\label{ddjf-2-2}

Reference documents are the Requirements Traceability Matrix (RTM) from Annex A of the GSEG TRS, the EWAS System Data Dictionary, the GSEG DDF engineering data registers, and the Programme Verification Plan and Verification Control Document listed in the TRS.

The DDJF will also contain references to technical analyses, option comparisons, simulations and verification reports. Each such document should have an identifier, a version and a link to the requirements under assessment.
