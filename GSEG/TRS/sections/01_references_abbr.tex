\subsection{1.3. Terms and Abbreviations}\label{terms-and-abbreviations}

\begin{itemize}
\item \textbf{Candidate Event:} preliminary detection reported by GEO for further assessment.
\item \textbf{Onboard Preliminary Trajectory:} preliminary trajectory computed onboard LEO.
\item \textbf{Ground Multi-Sensor Fusion:} combination of observations and the preliminary trajectory.
\item \textbf{Probabilistic Impact Area:} possible impact area with confidence level and uncertainty.
\item \textbf{Preliminary Warning:} first automatic warning following assessment of data from two LEO spacecraft.
\item \textbf{Abbreviations:} EWAS — Early Warning Alarm System; GSEG/\allowbreak{}SSEG — Ground/\allowbreak{}Space Segment; GSN — Ground Station Network; GIS — Ground Infrastructure Subsystem; C\&C — Command \& Control; DPS — Data Processing System; EWS — Early Warning System; MCC — Mission Control Center; DAS — Data Archiving System; GEO/\allowbreak{}LEO — Geostationary/\allowbreak{}Low Earth Orbit; ISL/\allowbreak{}OISL — Inter-Satellite Link/\allowbreak{}Optical Inter-Satellite Link; LOS — Line of Sight; TRS — Technical Requirements Specification; DDF — Design Definition File; DDJF — Design Justification File; ICD — Interface Control Document; RTM — Requirements Traceability Matrix; VCD — Verification Control Document; HIL — Hardware-in-the-Loop.
\end{itemize}
