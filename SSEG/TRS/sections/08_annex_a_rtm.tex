\section{Annex A: Requirements Traceability Matrix (RTM)}

In accordance with \textbf{ECSS-E-ST-10C Annex N} (\emph{Requirements traceability matrix DRD}, \textbf{AD-02}) and \textbf{ECSS-E-ST-10-06C} (\textbf{AD-03}), this annex establishes bidirectional traceability for Configuration Item \textbf{\texttt{CI-03}: Space Segment (\abbr{SSEG}, \abbr{WBS} Element \texttt{123456.03})}:
\begin{enumerate}
    \item \textbf{Backward Traceability (Subsection A.1, Table~\ref{tab:annex_a_backward_rtm}):} Maps all forty-nine (49) top-level system requirements (\texttt{R-001} through \texttt{R-049} defined in Chapter~5, Table~5.1 of \textbf{AD-01}) to the derived Space Segment technical requirements (\texttt{SSEG-REQ-<CAT>-<NNN>}) specified in Section~7 of this \abbr{TRS}. System requirements allocated exclusively to the peer Ground Segment (\abbr{WBS} \texttt{123456.02}) are explicitly identified along with the supporting Space Segment data products and interfaces that enable their execution.
    \item \textbf{Forward Allocation to Subordinate WBS Elements (Subsection A.2, Table~\ref{tab:annex_a_forward_wbs}):} Maps each of the twelve (12) \abbr{SSEG} requirement categories (77 normative requirements in total) down to the subordinate Level-3 flight system Configuration Items---\textbf{Satellite \abbr{LEO} (\texttt{SATL}, \abbr{WBS} \texttt{123456.03.01})} and \textbf{Satellite \abbr{GEO} (\texttt{SATG}, \abbr{WBS} \texttt{123456.03.02})}---and their constituent Level-4 subsystem WBS branches (\texttt{.01} through \texttt{.08}, aligned with Chapter~10 and Section~7.1 of \textbf{AD-01}).
\end{enumerate}
