\subsection{Design-Driving Requirements}

The following parent system requirements most strongly drive the Space Segment architecture:
\begin{itemize}
    \item \texttt{R-005}: Constellation size (6 GEO + 72 LEO) $\rightarrow$ Walker Delta $72/8/1$ + equatorial ring.
    \item \texttt{R-009}, \texttt{R-010}: Boost-phase detection ($P_d > 95\%$) $\rightarrow$ dual-band SWIR/MWIR staring payload.
    \item \texttt{R-011}: End-to-end latency $\le 60$~s $\rightarrow$ SSEG allocation $\le 45$~s; mandatory OISL relay.
    \item \texttt{R-015}: System availability $> 99.9\%$ $\rightarrow$ dual redundancy (\texttt{R-017}), 3-level FDIR.
    \item \texttt{R-016}: Lifetime ($\ge 7$~yr LEO, $\ge 15$~yr GEO) $\rightarrow$ altitude selection, Careful COTS, $\Delta v$ budgets.
    \item \texttt{R-018}: Space debris compliance $\rightarrow$ active deorbit propellant reserve, D4D, passivation.
    \item \texttt{R-023}, \texttt{R-024}: Onboard 3D trajectory and $< 5$~s lock-on $\rightarrow$ independent gimbal/FSM, OISL LOS exchange.
    \item \texttt{R-031}--\texttt{R-033}: COMSEC, anti-jamming, link margins $\rightarrow$ hardware encryption, laser OISL mesh.
\end{itemize}
