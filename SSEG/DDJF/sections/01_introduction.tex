\section{Introduction}
\label{sec:introduction}

This document constitutes the Design Definition and Justification File (\abbr{DDJF}) for the \textbf{EWAS Space Segment} (Configuration Item \texttt{CI-03}, \abbr{WBS} Element \texttt{123456.03}), prepared in accordance with ECSS-E-ST-10-02C Annex~K.

\textbf{Scope.} The \abbr{DDJF} covers the integrated dual-tier orbital constellation comprising:
\begin{itemize}
    \item \textbf{72 LEO Tracking Satellites (\texttt{SATL})}, \abbr{WBS} \texttt{123456.03.01}, operating at 1,000~km circular altitude, $80^\circ$ inclination, Walker Delta $72/8/1$ configuration.
    \item \textbf{6 GEO Detection Satellites (\texttt{SATG})}, \abbr{WBS} \texttt{123456.03.02}, operating at 35,786~km geostationary altitude, $60^\circ$ longitude spacing.
\end{itemize}

\textbf{Purpose.} This file provides a single traceable record of:
\begin{itemize}
    \item The design rationale and trade-off decisions at \abbr{WBS} Level~2 (Space Segment).
    \item Justification of the functional and physical architectures against parent system requirements (\texttt{R-001}--\texttt{R-049}, \textbf{AD-03}) and Level-2 requirements (\textbf{AD-01}).
    \item Technical budget allocations (mass, power, $\Delta v$, structural stiffness, radiation, latency, and bandwidth) with current margins.
    \item Verification strategy synthesis and requirement compliance status.
    \item Constraints imposed by the design on production, operations, transportation, and maintainability.
\end{itemize}
